# AGENTS.md — Documentation Context (Non-Obvious Only)

This file provides guidance to agents when working with code in this repository.

## Counterintuitive Structure
- `scripts/score.sh` (repo root) is a **simplified partial scorer** (60-point scale). The **authoritative scorer** is `pipeline/scripts/score.py` (100-point scale). They are not equivalent — always cite `score.py` for official scores.
- `templates/CHANGE_LEDGER.md` is a Markdown template for human-readable per-module logs. `pipeline/L2L_CHANGE_LEDGER.json` (generated by `ledger.py`) is the machine-readable ledger. They coexist and serve different purposes.
- `.bob/modes/*.md` files are per-mode auto-activation instructions consumed when a mode is activated. They are distinct from `.bob/rules/*.md` which are the actual enforcement rules.
- The `AUDIT_REPORT.md` output file lives in the **target app root** (not the L2L repo). `pipeline/templates/AUDIT_REPORT.md` is just the template.

## Key Context
- `pipeline/l2l.config.json` is the **only** file that changes when L2L is installed into a different target repo. All rules, modes, and templates are target-agnostic.
- `pipeline/scores/` accumulates snapshot JSONs. `ledger.py` auto-detects baseline (first) vs final (last) by sorted filename order — filenames are ISO timestamps.
- The `dashboard/index.html` visualizes scores from `pipeline/scores/`. It reads the JSON files directly.
- Mode file permissions are enforced in `.bob/custom_modes.yaml` via `fileRegex` within the `edit` group — not just by convention.
